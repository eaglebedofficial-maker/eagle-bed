    Connect Trading 212

    1. In the Trading 212 app, choose your Invest or Stocks ISA account, then open Settings, then API (Beta), and generate a key. Tick only the read permissions (account, portfolio, history, metadata). Leave order permissions unticked.
    2. Copy the API key and the secret. The secret is shown once.
    3. In the cloud environment settings (environment menu, Edit), add T212_API_KEY, T212_API_SECRET and T212_ENV=live, and allow the domain live.trading212.com. Never paste the key into a chat.
    4. Press Restart engine on the Desk. This card shows Connected when it works.
