## A. Agent inventory

**In short:** HQ has **65 switchable agents plus the Manager**, 66 in all. The boot screen says "66 agents" (`AGENTS.length+1`, L2629). `settings/main.agentsOff = ["teardown"]`, so the switch panel correctly shows "64 of 65 agents on" (L3110). All agents start on by default (`agentsOff` is empty until the owner switches one off, L1106).

**What an agent really is.** An agent is one entry in `AGENTS` (L677–741): a name, a role prompt and a list of up to 8 tools. No agent runs on its own timer. An agent works only when the Manager gives it a task inside an "order" (`startOrder` L1965, `runTask` L1632). The order can come from the owner, a chat ORDER line, a button, the watchdog, or auto-resume. With `review:true` (the current setting) each task makes **2 Claude calls**: a quick-tier draft, then a default-tier final. Both calls carry tools. Agent tools are **read-only**:
- OR = OpenRush (`rush()`, L1435, cached 24h, or 6h for search results, Search Console and GA4)
- SH = Shopify search/ShopifyQL
- ZA = Google Ads report through Zapier (`adsReport`, cached 12h, at most 2 a day)

Only a few code paths write anything:
- creating new Shopify product drafts (L1687)
- SEO title apply/fix (L2031, L2069 `fixSuffixes`)
- Facebook/Instagram posting (L2142)
- pausing or enabling Google Ads campaigns (owner only)
- adding jobs to the Claude Code queue `codequeue` (L916)

Phrases like "uses the REA/graphify/CGI/Higgsfield skill" in the prompts are **text only**. That work happens only if a `codequeue` job is later picked up by the 07:47 Daily Autopilot.

## B. How the system fits together

**In short:** HQ is the dashboard and database. Scheduled cloud tasks do the real work, and Zapier is the only route to social and Ads.

- **HQ page** (claude.ai artifact). It uses `db` (collections: settings, runs, posts, videos, cinema, leads, outreach, inbox, usage, cache, codequeue, memory, worklog, aivis, seo…), `sample` (Claude), and `mcp` (Shopify, OpenRush, Zapier). **While the page is open** it runs:
  - `autopilotTick` every 60s: plans posts if fewer than 4 days are ready, runs the Monday scan, and posts due FB/IG posts itself
  - `autoResume` every 2 min: re-runs unfinished orders
  - `watchdog` every 30 min: Shopify plus a Zapier Ads read. If it finds alerts, it can auto-start a full order (L1569)
  - `fixSuffixes` at load (L3255–3261)

## E. Top 10 waste and risk items

1. **Cinema keeps failing every day.** All 10 runs 14–18 Nov hit Gemini 402. `autoCinema` is not set, so it stays on. The Monday AI check and the RUNBOOK step 3 "stop" also block steps 6/6b/6c on failure (`ops/cinema/RUNBOOK.md` L20–22, L60–79). **Fix:** set `settings/main.autoCinema=false` until Gemini is topped up.
2. **Assembly claim still in task prompts.** The social post task says "our own team delivers and assembles", and the Email Marketing 09:53 prompt says "free GB delivery with assembly". Both contradict BRIEF (18 Nov, £50 assembly; `ops/BRIEF.md` L20). Only `ops/email/trade-agent-brief.txt` L14 is correct.
3. **Zapier budget won't cover a full month.** Photo posts cost 4 tasks × 3 a day = 12 a day (about 360 a month). Videos add 8 a day (about 240) once Gemini works. Pinterest, GBP and the Ads reads (up to 60) bring the total to about 700 against a safe budget of 710. GBP has used 9 tasks since 10 Nov, although the runbook says once per Monday.
4. **Zapier counter can lose counts.** HQ `zapCount` overwrites the usage doc with `.set()` from its local copy, without a version check (L2847–2849). It can wipe increments the scheduled tasks made at the same time, so the meter can under-count.
5. **Three things run the same HQ orders.** The CEO sprint (step 2), the Daily Autopilot (step 3, sonnet agents) and the browser's `autoResume` (L2231, no owner check) all run queued HQ tasks, which risks duplicate work and duplicate spend.
6. **HQ page acts on its own while open.** The watchdog can start an order once a day (L1569). `autopilotTick` posts FB/IG directly (L2224–2226), on top of the scheduled social task, so a post can go out twice if the task's status write lags. `fixSuffixes` writes Shopify on load (L3261).
7. **Dead or superseded agents.** Video & Music Studio, Higgsfield AI Studio, Cinematic AI Director and CGI Photos all depend on missing keys or credit. The Daily Autopilot step 6b still creates "waiting" photo-video docs and nags the owner (stale prompt).
8. **Too many agents for the work.** 65 agents with heavy overlap (section A). The Manager prompt itself warns "Claude usage is limited" (L866). `review:true` doubles cost (L1053, L1636).
9. **Social task is over-provisioned.** It is pinned to Opus with 7 connectors (Canva, Supermetrics, OpenRush and Docs unused) and starts a fresh session 3 times a day.
10. **Fragile or stale dependencies.**
    - The email top-up's brief lives in the scratchpad (`tb-brief.txt`), which gets wiped on restart.
    - The daily report reads `ops/seo-types/pin-queue.json`, but the RUNBOOK L71 says the HQ `pins` collection is the source of truth.
    - The `codequeue` is only processed by the 07:47 run.
    - "Trading HQ" (hourly) shares the account's usage.
